========
Features
========

To access the CrateDB EE Console, simply log in with any of your CrateDB users credentials.

CrateDB EE Console provides an overview of your CrateDB cluster.
You can also explore your table schemas, check the users in your cluster and a monitoring
section where you can see the state of your CrateDB nodes and tables.
