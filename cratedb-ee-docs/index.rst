CrateDB Enterprise Edition
==========================

CrateDB Enterprise Edition brings additional features to your on-premises CrateDB cluster.

The CrateDB EE Console can be installed separately, allows you to log in with your own
CrateDB users and brings a web interface with many features like monitoring, a SQL
console, running queries periodically and more!
